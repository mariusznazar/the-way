# Handing work on to another skill of the-way

This file holds, once, the way a skill of the-way hands work on to another skill of the-way. A skill
that hands work on names this file and reads it when the first hand-over comes.

In the-way itself, the other skill is read as a file, not called, since Claude Code does not offer the entry points of the-way's skills to the model: its `SKILL.md` stands at the path that the list of skills in the entry point the session was started with gives, or, where the session was started without one, in the file under the checkout or worktree the session works in whose frontmatter has the line `name: <that name>`, which a search of the files that git lists as `SKILL.md` finds. Read that file there in full and follow it.

In a product, the other skill is the project skill of that name with the `the-way-` prefix, never a personal copy of the same name.
