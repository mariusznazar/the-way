- *Source*: open the address and copy the passage as the template's "Source" gives it; a passage
  missing there is a question in step 4. For a reading, run on the host or the service a command or
  a call that only reads its state, and copy its output and the version of each tool the result
  depends on; a reading only the human can run is a question in step 4 naming the command. For a
  reading in a service, take the call from the service's own documentation, ask for the fields the
  sentence rests on by name in the request or keep them with a filter, and run it once to see what
  the answer holds before it is quoted: an answer that carries a token or a password beside those
  fields is not quoted, and where you find no narrower call, that is a question in step 4. For a
  page without editions, find the archived copy through the archive's CDX index of captures, not
  its availability lookup, which misses captures that exist.
