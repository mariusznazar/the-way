# Invariant entry examples

The entries of this repository's own invariants, `foundations/invariants.md`, that show the form
of an entry, named by identifier. Each is read there, in the commit of the-way a product pins, never
copied here.

- `instruction-file-imports` — a sentence about real files, which a test running the check on
  those files keeps
- `gate-exit-code` — a sentence about what a command reports, which the command's tests keep by
  feeding it input made up for them
- `script-imports` — `every` in *Part*, with a fact in *Rests on*
- `fingerprint-definition` — a fact of an outside standard behind a value the sentence names
- `return-step-record` — a sentence that holds only where `{merge-onto}` exists, with no cheap test,
  which review keeps
