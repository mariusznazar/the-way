# Invariant entry examples

The entries of this repository's own invariants, `foundations/invariants.md`, that show the form
of an entry, named by identifier, one for each form `template.md` describes. Each is read there, in
the commit of the-way a product pins, never copied here.

- `log-entry-field-presence` — a method that runs a format guard on the real file
- `decision-guard-overdue-review` — a method that runs the tests of a guard, for a sentence about
  what the guard reports
- `file-part-assignment` — `every` in *Part*, with a fact in *Rests on*
- `fingerprint-definition` — a fact of an outside standard behind a value the sentence names
- `return-step-record` — a `TODO` method under a sentence that holds only where `{merge-onto}`
  exists
