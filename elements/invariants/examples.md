# Invariant entry examples

The entries of this repository's own invariants, `foundations/invariants.md`, that show the form
of an entry, named by identifier. Each is read there, in the commit of the-way a product pins, never
copied here. Until the foundation is migrated, these entries keep the earlier form the template's
last sections describe; read them for their sentences, links and *Part*.

- `log-entry-field-presence` — a sentence about a real file, which a test running the check on
  that file keeps
- `decision-guard-overdue-review` — a sentence about what a check reports, which the check's tests
  keep by feeding it input made up for them
- `file-part-assignment` — `every` in *Part*, with a fact in *Rests on*
- `fingerprint-definition` — a fact of an outside standard behind a value the sentence names
- `return-step-record` — a sentence that holds only where `{merge-onto}` exists, with no cheap test,
  which review keeps
