# Glossary entry examples

The entries of this repository's own glossary, `foundations/glossary.md`, that show the form of an
entry, named by term, one for each form `template.md` describes. Each is read there, in the commit
of the-way a product pins, never copied here.

- `invariant` — both fields `none`
- `gate` — *Avoid* holds another word for what the term names
- `foundation` — *Not* names a meaning the word no longer carries, with the quoted word that
  carries it now
