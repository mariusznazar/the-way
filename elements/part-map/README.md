# Part map

The part map is a set of rules, not a description of the current state. It holds the parts of
the product, each with its responsibility and a rule for assigning files to it; the allowed
dependencies between parts, with their direction; the external context — who and what
exchanges anything with the product; the criticality of parts and of critical flows; and the
surfaces that someone outside the product relies on, each with the path by which it may change.

This description grows into the element's template as the element goes through its steps.
