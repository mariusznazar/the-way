usage: format_guard.py [-h] [--base BASE] [--record RECORD] [map]

Check a part map against its template.

positional arguments:
  map

options:
  -h, --help       show this help message and exit
  --base BASE      the commit the task branch left the main branch from, to
                   compare the list of known violations, the identifiers of
                   the map and the computed criticality of the parts with;
                   `none` where it does not exist, which records those checks
                   as unchecked
  --record RECORD  the JSON Lines file, created or overwritten, that receives
                   a verdict for each invariant a check cites
