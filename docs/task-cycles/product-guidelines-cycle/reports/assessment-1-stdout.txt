usage: format_guard.py [-h] [--base BASE] [--merge-onto MERGE_ONTO]
                       [--today TODAY] [--record RECORD]
                       [log]

Check a decision log against its template.

positional arguments:
  log

options:
  -h, --help            show this help message and exit
  --base BASE           the commit the task branch left the main branch from,
                        to compare the log with; `none` where it does not
                        exist, which records those checks as unchecked
  --merge-onto MERGE_ONTO
                        the commit of the main branch a merge is made onto;
                        only with it are the copies of a version both logs
                        hold compared, the fingerprints relations carry
                        compared with the current binding part, and `TODO` in
                        the log reported as an error; `none` where the main
                        branch does not exist, which records those checks as
                        unchecked
  --today TODAY         the date passed check-by dates are measured against
  --record RECORD       the JSON Lines file, created or overwritten, that
                        receives a verdict for each invariant a check cites
