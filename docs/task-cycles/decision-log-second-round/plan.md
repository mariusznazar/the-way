How the change is divided. Every edit of `foundations/decisions.md`, of `foundations/invariants.md`, of `foundations/part_map.md` and of `foundations/glossary.md` is a foundation entry written by the agent of the plan's *Foundation entries* before Slice 1, never a slice: the log is 971 571 characters, which `task-cycle/slice_size.py` reads whole for any slice that changes it, and that is over the limit of one slice on its own. A slice changes files outside `foundations/` only: the skills, templates and scripts that carry a rule and name the numbers. After the foundation entries the check `python -B elements/common/foundation_check.py` reports a line for each reference in a file outside `foundations/` to a number that left the log (it reports a name that is withdrawn or names no entry); each slice makes those lines for its files disappear, and the last slice leaves the exit code 0. The slices read an entry that left the log at the base `ec7929d`, where it still stands: `git show ec7929d:foundations/decisions.md`; the line ranges named in *Read* are its lines at the base. The files of the slices are disjoint, and no file of the foundations stands in a *Change*.
