## What you will see

When an agent leads a project plan, each task it refines now gets its line in the product's backlog, with the right status, instead of you adding the lines by hand after every round. The refiner of a task that has no line yet makes it in the first turn in which it writes the task's document: it links the document, gives the line the status of a task still being refined, and, for a task of a plan, copies the plan's dependencies onto it. The refiners of one round do this at the same time, with no queue; the small risk that two writes to the file land in the same instant and one line is lost is accepted, as you decided. When you accept a document, the agent leading the round moves the line to ready together with the document's status and the plan's row. If a line could not be made in the first turn — the rules for it were not yet known — or never existed, it is made in the first later turn that can, and at acceptance the leading agent makes it already ready.

The rules for a line — the status of a new line, its move to ready, the form of its dependencies — are no longer written at the product or in the-way's skills. They are read from the rules of the place where the product keeps its tasks, which the agent finds through a second entry, next to the tasks' place, in your private locations file. The product's instruction file names only that entry. Where the entry or the file it points to is missing, the agent asks you once and offers to add the entry. The same holds for refining a task by hand. The instruction file of the-way itself now names this entry instead of repeating the old sentence about moving a line to ready.

### Underneath

The line's identifier, which dependencies point at, is computed by a rule from the plan's file name and the task's name in the plan, so that a refiner can write it into a dependent task's line before the other task's line exists. The writing rules for a refiner, the decisions that bind it and the skill text were changed together, with one place in the skills that holds the rule of when a line is made.
