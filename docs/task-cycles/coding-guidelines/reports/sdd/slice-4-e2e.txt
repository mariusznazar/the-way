## Rules

### Linter

- **Decision:** ABC-01@72e3c276
- **Invariant:** lint-clean@4cfd7959
- **Good:** a function reads every variable it declares.
- **Bad:** a function declares a variable it never reads.

Run ESLint with the product's configuration; fix a report of a rule that blocks in the file
that gives it, with no inline suppression.

```good lint-clean src/lib/sum.ts
export const sum = (a: number, b: number) => a + b;
```

```bad lint-clean src/lib/sum.ts
export const sum = (a: number, b: number) => {
  const unused = 1;
  return a + b;
};
```

### Formatter

- **Decision:** ABC-02@c17d8fa7
- **Invariant:** format-clean@5e3206a7
- **Good:** a file stands as Prettier writes it.
- **Bad:** a file keeps spacing Prettier would change.

Let Prettier write every file of the code before the change is offered.

```good format-clean src/lib/sum.ts
export const sum = (a: number, b: number) => a + b;
```

```bad format-clean src/lib/sum.ts
export const sum=(a:number,b:number)=>a+b
```

### Dependency audit

- **Decision:** ABC-03@8784e848
- **Invariant:** audit-clean@c8479c9e
- **Good:** the change brings in a version npm audit flags nothing in.
- **Bad:** the change brings in a version with a known vulnerability of high severity.

Run npm audit on the change before taking in a dependency.

```good audit-clean tools/one/package-lock.json
{{"lockfileVersion": 3, "packages": {{"node_modules/left-pad": {{"version": "1.3.0"}}}}}}
```

```bad audit-clean tools/one/package-lock.json
{{"lockfileVersion": 3, "packages": {{"node_modules/minimist": {{"version": "0.0.8"}}}}}}
```

## Rules

### Input validated with the shared schema

- **Decision:** ABC-04@ea21074d
- **Invariant:** endpoint-validates@9666b706
- **Good:** an endpoint parses its input with the shared schema.
- **Bad:** an endpoint reads its input unchecked.

Parse the input with the shared schema before reading it.

```good endpoint-validates src/api/carts/route.ts
import { handle } from "../handler";
import { schema } from "../schema";
export const POST = handle((input: unknown) => schema.parse(input));
```

```bad endpoint-validates src/api/carts/route.ts
import { handle } from "../handler";
export const POST = handle((input: unknown) => input);
```

### Through the shared handler

- **Decision:** ABC-04@ea21074d
- **Invariant:** endpoint-handler@8c2ca199 · guidelines-form@7196030f
- **Good:** an endpoint answers through the shared handler.
- **Bad:** an endpoint answers on its own.

Answer every request through the shared handler.

```good endpoint-handler src/api/carts/route.ts
import { handle } from "../handler";
export const POST = handle((input: unknown) => input);
```

```bad endpoint-handler src/api/carts/route.ts
export const POST = (input: unknown) => new Response(String(input));
```
