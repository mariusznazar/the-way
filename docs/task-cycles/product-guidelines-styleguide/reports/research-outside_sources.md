## C. 10x-ui (UI = SKILL.md, CHK = ui-quality-checklist.md)

### Purpose and scope
- "Audit and improve ONE view that already renders, as a normal 10x change with a design-system contract" (UI:4–5). "Not a generator for a view that does not exist yet, not a component catalog, not a Playwright course." (UI:12–14)
- "**This skill iterates on UI that is already there.** It assumes a view you can open and screenshot" (UI:23–24). "It does not replace the chain … It is the entry point" (UI:28–29).
- Reads `context/foundation/lessons.md` once if present (UI:36).

### Modes / entry (on invocation, UI:51–67)
There are no named modes; target resolution has three branches: existing change folder → resume at first undone router step (UI:54–55); route or view file → suggest change-id, "in `change.md` name **one** view and the token source (or motif)" (UI:56–58); no argument → ask which view and stop (UI:59). Archived paths refused (UI:60–61).
- Pre-audit "(minutes, not research)": locate value source, shared components directory, agent rules files (`CLAUDE.md`, `AGENTS.md`, `.cursor/rules/*`, `.windsurfrules`, `copilot-instructions.md`) and run the scan; "Report the counts — they tell you which contract variant applies." (UI:62–65)
- "Playbooks" act as sub-modes (UI:279–288): theme/restyle of one view (default), inherited agent slop, single component ("skip the token phase only if its values already come from tokens"), dark mode, focus/keyboard pass.

### When / which view / "Not now" (UI:38–49)
