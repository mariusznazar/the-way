A guard run inside `.the-way` without a file checks the-way's own files. Records of a run (`--record`) go under `.runs/`, which `.gitignore` must keep ignored.
+
+The main branch is the branch task branches merge into. In a clone, `git symbolic-ref --short refs/remotes/origin/HEAD` names it as `origin/<branch>`; otherwise ask the human.
