# Placing a single rule

How the skill places one rule, in the mode place.

1. Name what lets the rule in, as "When to add a rule" gives it; a rule that section does not let
   in is not placed.
2. Answer the two questions of "Where a rule stands" for the rule; for a rule that must hold every
   time, propose first the mechanism that section gives, and the instruction its note allows.
3. Search the instruction files for a rule on the same subject, as "When to add a rule" asks before
   adding.
4. Word the rule by "How to write a single rule", with the command or file that leaves its trace.
5. Show the place, the wording and what happens if it is left out, and write only after approval.
