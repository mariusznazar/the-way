# The return step

Read by the agent that takes the return step, step 11 of `implement-task`: the one author resumed
for it, or a fresh agent with `make-change` (`task-cycle/change/SKILL.md`). "It" below is that
agent.

It compares with the code the entries the change writes or changes, those the task names and those
the search of the foundation found, and the part map of the touched parts, and corrects in the same
change whatever no longer matches (WAY-11). It writes, as the foundation step writes, each source
outside the product that the change rests on and the foundation does not hold, as an environment
fact; a word the change uses in a meaning for which WAY-95 gives it an entry, by following
`elements/glossary/skill/SKILL.md`; a row of *Settlements to record* or a projected entry the code makes
true that the foundation step missed; and a choice that binds after the merge
(WAY-36). A row and a choice go to the place the questions of the decisions template give it
(WAY-11, WAY-134), where the log is one such place; where the place is another, no entry is written.
Where a decision the change writes carries a pair of examples and a test holds part of its sentence,
it removes that part from the pair, names that test by the clause `tests:` of the decision's
*Verification*, and leaves a pair only for a part no test holds. Where the task or its spec
explicitly excludes an entry for a choice, that exclusion prevails over the rule for a choice that
binds after the merge: the choice stays a row of the questions table. It writes an invariant only
for a rule the task, a decision or the human sets, never for behaviour merely because no invariant
covers it; every other choice stays a row of the questions table. No entry is deferred: one this
request does not write is neither proposed nor listed for later, and the review findings of the
request are no foundation entries. A term used against its entry takes the use corrected and no
entry.

The report of the step names the place each settlement it writes went to, as the record's
*Return step* gives it.
