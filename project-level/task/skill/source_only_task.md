# Task using project settlements without plan membership

Use this file only when the task uses a project's settlements but is not a member of its plan.

## Step 1: read the project source

Read the definition in full but take no plan assignment or dependency from it. Select the goal,
scope, technology, projected entries and open questions relevant to the stated task.

## Step 3: reconcile brought-in questions

Reconcile the project questions explicitly brought into this task, without absorbing the project's
other work. Answer a question that determines required product behavior in the task document;
reproduce an implementation question under `Questions carried to cycle`. Do not let a question in
the task's scope disappear.

## Step 4: mark projected entries

A source-only task takes no plan assignment, but its cycle writes a projected entry its code will
make true: mark that entry under *Decisions in play* with the part made true now, also when the plan
assigns that entry to another task (WAY-124, WAY-126).
