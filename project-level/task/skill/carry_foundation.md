# Carry the foundation decisions

Carry under *Decisions in play* the current decisions the task touches, as "Reading the foundation"
of step 1 selects them for the task's scope, each by its identifier with its current wording
quoted. If a project definition is a source, bring in its relevant approved projected wording. For
plan assignment or source-only handling of projected entries, follow the file named in step 1 for
that task relation (WAY-124, WAY-126).

For a plan member, follow `project_plan_task.md` to compare numbered work, dependencies and
projected entries with its plan item. A mismatch returns to the plan, not an unrecorded change in
this document.

If the task would contradict a current decision or a projected entry, show the conflict and its
consequences. The human chooses whether to change the task or reopen the upstream settlement. Do
not replace approved wording with the agent's paraphrase. The exception is the decision a run of
`settle-technology` changes at the human's word (WAY-265): *Decisions in play* quotes it, and the
human is not asked again.
